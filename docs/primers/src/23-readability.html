Readability · Update
P523 · UPDATE
TL;DR — Some fellas said the app was hard to read. Fixed in three layers: (1) the app now respects your phone's system text-size setting, (2) the two narrative screens — match report + help — got a small universal bump, and (3) there's a new Compact / Regular / Large toggle on Profile so anyone can nudge it bigger. All three stack on top of each other.

Three levers, layered

Lever 1
Match report + Help got a small bump

Body text on the match-report and help-article pages went from 13→14pt; the report summary lede went from 14→16pt. Help article paragraphs went 14→15pt. Universal — no opt-in.

Everyone · automatic

Lever 2
Text-size toggle on Profile

New card under Notifications: Compact · Regular · Large. Default is Compact (today's look — nothing changes). Regular is +10%, Large is +20%. Applies instantly, saved per device.

Anyone · opt-in

Lever 3
Respect the phone's own text setting

iOS Settings → Safari → Page Zoom and Android Accessibility → Font Size now flow through to the app. Set your phone once, every app respects it — WF now included.

Anyone with OS text-size on · automatic

Comfortable for you, not everyone else

The stack is compositional. A player with iOS text set to Larger who also picks Large in Profile ends up meaningfully bigger than default — and the layout expands with them rather than clipping.

What we deliberately didn't change

  • Ceefax-style tables — teams roster, finance rows, admin panels. The dense mono look is the aesthetic, and the readability complaints weren't about numbers-in-columns.
  • Badges, pills, page IDs — meant to stay small and out of the way; scaling them ruins the visual hierarchy.
  • Muted grey text colour — checked the contrast against the dark background, comes in at 7.4:1 (AAA). Not the bottleneck.

Where to go next

  • Try the toggle: Profile → Text size. Poke Regular for a few days; if it feels good, Large is right there too.
  • Setting your phone's system text size once means every app you use — WhatsApp, mail, banking — respects it. That's the real fix if you've been squinting anywhere.
  • Something still hard to read? Ping admin with which screen — targeted spot-fixes are cheap now the plumbing's in place.
