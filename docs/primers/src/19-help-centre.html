Four categories, seven articles at launch. Category ordering is fixed (Basics → Match night → World Cup → Money); articles inside each keep the roughly "you'll need this first" order.

Search

Type anything into the box at the top: it fuzzy-matches against title, blurb, and the full article body. So "grace period" finds Fees & credits, "APN" finds the Notifications article's troubleshooting section, "clean sheet" finds nothing (yet — that's the GK card article on the backlog).

Offline-ready. Articles ship inside the app bundle — not fetched at runtime. Once the service worker has cached the app, the Help Centre works on the tube with no signal. No spinners, no "failed to load".

Setting up notifications

Get a push on your phone when the MOTM/DOTD vote opens on Thursday night. Once you've enabled it, no more scrolling WhatsApp to find the ballot link — the app taps you on the shoulder.

On iPhone

iOS only allows web push from apps you've added to the Home Screen. Two-step setup:

  • In Safari, tap the Share icon → Add to Home Screen.
  • Open the app from the Home Screen (the new icon, not Safari). Go to Profile → Enable notifications. Allow when prompted.
On Android

Works from Chrome directly — no Home Screen step needed. Profile → Enable notifications → Allow.

Same teletext styling as the rest of the app — yellow for emphasis, cyan for links/pointers, green mono for anything the app displays or you'd type. Tables, lists, code blocks are all styled inline; every article ends with the same "Anything wrong? Ping admin via Feedback" footer.

Missing an article? The feedback loop

▶ IF YOU SEE A GAP

Search comes up empty → tap Feedback at the bottom of the Help index (or in the More menu). Type what you were looking for.

■ WHAT HAPPENS NEXT

Admin gets the ping. New articles land in the next app deploy as .md files — same cycle as adding a new feature. No spreadsheet, no CMS.

What hasn't changed

  • The 18 primer PDFs in the WhatsApp group aren't going away — they're the shareable-outside-the-app version. The Help Centre is the "I'm in the app right now and stuck" companion.
  • The Feedback tab still works the same way — just now with a natural entry point from the help pages.
  • Every existing feature still lives where it always did; the Help articles point at them, they don't hide them.

Under the hood (one paragraph)

Articles live as markdown files in src/help/*.md. They're imported at build time via Vite's ?raw suffix so the strings ship in the JS bundle — no runtime fetch, no failure modes, works offline. To add or edit an article, drop/edit a .md file and register it in src/help/index.ts. Ship on the next merge.
