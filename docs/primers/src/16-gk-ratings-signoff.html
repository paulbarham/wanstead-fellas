How we decided

Three GK-specific signals:

  • Goals conceded per fixture → the reflexes / positioning ratings
  • Clean-sheet % → overall rating (a keeper's most honest scoreboard)
  • MOTM votes → overall rating (keepers rarely win — when they do, it means something)

Guard-rails: minimum 4 appearances; changes capped at ±2 per rating per pass. Sample caveat: goals-conceded is a proxy — we don't yet record which keeper played which fixture, so it assumes they went the whole match. Fine for now (keepers don't rotate); will sharpen when we track it.
