TL;DR — The Next Game tab is now far less of a scroll. The 73-row wall of signups has been broken up with a search box, coloured tier dots, a tighter masthead, and a collapsible Not-In list for admin. Force-refresh the app and have a look.

What's new at a glance

  • Search box at the top of the lists — type a name to jump to it.
  • Coloured tier dots replace the cryptic SUB / WTP* / WTP suffixes.
  • Consolidated masthead — weather + signup count + format share one row.
  • Smaller My Squad pills for kid toggles, so they don't compete with the main I'm In button.
  • Not In (admin only) now collapses by default, with tier filters + sorted by recent attendance.

Tier dots — what the colours mean

Every player row used to end in a small text label (SUB / WTP* / WTP). Four flavours of the same word at 10pt is hard to scan. Now it's a single coloured dot:
