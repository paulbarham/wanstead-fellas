# Signing up for a match

Everything happens from the ⚽ **Next Game** tab.

## The In / Out button

Big green **I'm In** button at the top. Tap it once you know you're playing. It flips to **Drop Out** — tap again if plans change.

- The tab shows a **live count** of confirmed players and reserves
- Cap is **32 confirmed players** per match; anyone above that goes on the reserve list automatically
- If someone drops out and there's space, the **next reserve is promoted** automatically — you don't need to do anything

## Deadlines

| When | What |
|---|---|
| **Fri 10pm** (week before) | Sign-up opens |
| **Wed 10pm** | Sign-up locks — no more changes without asking admin |
| **Thu 21:00** | Kick-off |

Drop out **after Wed 10pm** and you owe a **£2 late-drop fine**, unless a reserve steps in seamlessly (in which case admin waives it).

## Player tiers

Your tier decides what happens when the game is over-subscribed:

- 🟢 **Subscribed** — you pay monthly; you get priority. You'll never be bumped by a WTP.
- ⭐ **WTP Priority** — pay-per-play + priority slot. Jumps the WTP queue.
- ⚫ **WTP (want-to-play)** — pay-per-play. Latest WTP signups get bumped first if the game is full.

If you're a WTP and get bumped, you'll see it in the app and there's no charge — the £5 fee only lands if you actually play.

## Kids and family (My Squad)

Parents can manage linked kids from the Profile page under **My Squad**. Sign them up the same way — tap the pill for each kid to toggle their availability.
